# Fakturace

Webová aplikace pro fakturaci, zálohy, úhrady, pokladnu a evidenci zákazníků.

## Technologie

- Next.js 16 (App Router)
- React 19
- TypeScript
- PostgreSQL (připravujeme)

## Spuštění

```bash
npm install
npm run dev
```

Aplikace běží standardně na `http://localhost:3000`.

## Aktuální stav

Základní aplikační shell, responzivní layout, dashboard a připravené routy jednotlivých modulů. Databáze a autentizace budou přidány v další fázi.
